# 🐳 Dockerized Web Application

A simple containerized web application built using Docker and Nginx as part of my AWS Cloud & DevOps learning journey.

## 📌 Project Overview

This project demonstrates how to package a web application into a Docker image and run it as a container using Docker Compose.

The project also includes environment configuration and a Docker health check.
